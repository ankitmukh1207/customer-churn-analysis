# 🔥 Why Are We Losing Customers? — Churn Deep Dive + Action Plan

> A complete end-to-end Data Analytics project using SQL, Python, and Power BI

---

## 📌 Problem Statement

A telecom company is losing customers but doesn't know why. This project analyzes churn across multiple dimensions — time, customer type, feature usage — identifies root causes, builds a predictive ML model, and delivers an actionable **Churn Playbook** to reduce revenue loss.

---

## 📊 Dataset

- **Source:** IBM Sample Data — Telco Customer Churn  
- **Size:** 7,043 customers × 21 features  
- **Target Variable:** `Churn` (Yes/No)  
- **Key Features:** tenure, MonthlyCharges, Contract, InternetService, TechSupport, OnlineSecurity

## 📈 Key Findings

| Finding | Insight |
|---------|---------|
| **Overall Churn Rate** | 26.5% — above industry average |
| **Month-to-month contracts** | ~42% churn rate vs 3% for 2-year contracts |
| **New customers (0-3 months)** | Highest churn — onboarding problem |
| **No OnlineSecurity** | 2x more likely to churn |
| **Electronic check payment** | Highest churn among payment methods |
| **Fiber optic users** | Churn more than DSL — service quality issue |

---

## 💰 Business Impact

- **Monthly Revenue Lost:** ~$139,130
- **Annual Revenue Lost:** ~$1.67 Million
- Retaining **10% more customers** = ~$167K saved per year

---

## 📋 Churn Playbook (Action Plan)

| Trigger | Action |
|---------|--------|
| New customer, inactive ≤ 3 months | 📧 Send re-engagement email |
| High-value customer, no TechSupport | 🎯 Assign dedicated support agent |
| Internet user with no OnlineSecurity | 🔒 Offer security add-on (free trial) |
| Long-tenure, month-to-month contract | 💰 Offer annual plan discount |
| Churn probability > 60% | 🚨 Urgent retention call |
